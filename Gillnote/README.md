# Gillnote

AI wild-mushroom field coach — shoot or import cap / gill / pore stills, rank species hypotheses on a vertical confidence stack, inspect an oversized gill/pore closeup bar, review informational caution chips, chat lookalikes, annotate overlays, and hear a TTS field brief.

**Hard compliance:** every ID / edibility / foraging surface states `非可食认证 / not an edibility certification`. Never implies safe to eat.

- Bundle ID: `com.lingguang.gillnote`
- Palette: `#9A3412` / `#FFF7ED` / `#0284C7`
- Simulator: iPhone 17 Pro only (prefer `B14CC0EA`)
- No AppIcon / LaunchScreen assets in this UltraLite build
