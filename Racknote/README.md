# Racknote

AI wine-cellar coach — shoot or import labels, place bottles in bins, chat drinking windows and pairings, hear a pull brief.

**Compliance:** 非侍酒认证 / not a sommelier certification · 非投资建议 / not investment advice · 21+

- Bundle: `com.lingguang.racknote`
- Palette: `#3730A3` / `#EEF2FF` / `#EA580C`
- UI: cellar row/bin grid + large label-OCR hero card + drinking-window aging timeline
- No AppIcon / LaunchScreen in this UltraLite build
- Simulator: iPhone 17 Pro only (prefer B14CC0EA)
